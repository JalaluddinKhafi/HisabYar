# حساب‌یار

دفتر آفلاین درآمد و مصارف به افغانی و دالر، برای اندروید ۶ و بالاتر. جمع و ماندهٔ هر ارز جدا محاسبه می‌شود؛ تبدیل نرخ ارز وجود ندارد. تاریخ‌ها میلادی و بر اساس تاریخ محلی گوشی هستند.

## استفاده

- مبلغ مثبت با حداکثر دو رقم اعشار وارد کنید. ارقام فارسی، عربی و انگلیسی پذیرفته می‌شوند. جداکنندهٔ هزارگان ننویسید.
- نوع ثبت، ارز، دسته و تاریخ را انتخاب کنید؛ منبع و توضیح اختیاری‌اند.
- برای ویرایش یک ثبت آن را لمس کنید؛ برای حذف فشار طولانی بدهید. آخرین حذف تا بسته‌شدن برنامه قابل بازگردانی است و با چرخش صفحه حفظ می‌شود.
- فیلتر ارز، نوع و تاریخ و جستجو فقط فهرست را تغییر می‌دهند؛ خلاصهٔ بالای صفحه همیشه مربوط به همهٔ ثبت‌های ماه جاری است.
- فهرست در هر مرحله ۵۰ ثبت نشان می‌دهد. گزارش روزانه، ماهانه و مصارف بر اساس دسته در دسترس است.

## پشتیبان و بازیابی

«ذخیرهٔ فایل پشتیبان JSON» را انتخاب و محل فایل را مشخص کنید. برای بازیابی، فایل را باز کنید؛ برنامه تمام ثبت‌ها را بررسی کرده و پیش از جایگزینی تأیید می‌گیرد. بازیابی تمام داده‌های فعلی را جایگزین می‌کند؛ ابتدا پشتیبان بگیرید. CSV برای مشاهده در برنامه‌های جدول است و برای بازیابی استفاده نمی‌شود.

حد فایل ورودی ۸ مگابایت و حد تعداد ثبت‌ها ۱۰۰۰۰ است. فایل‌های قدیمی که آرایهٔ JSON هستند نیز پذیرفته می‌شوند. اگر دادهٔ محلی خراب باشد، نوشتن و بازیابی مسدود می‌شود؛ «خروجی خام» را ذخیره کنید و برای تعمیر بررسی کنید. بدون حفظ نسخهٔ خام، برنامه یا داده‌های آن را پاک نکنید.

## ساخت APK با GitHub

در بخش Actions گردش‌کار `Build HisabYar APK` را اجرا کنید. پس از موفقیت، `HisabYar-debug-apk` را از Artifacts دانلود و ZIP را استخراج کنید. APK نسخهٔ آزمایشی است. دستور ساخت محلی و اجرای آزمون‌ها در [README](README.md) آمده است.

گزارش مشکلات اولیه در [بررسی](docs/REVIEW_FA.md)، محدودیت‌ها در [حریم خصوصی](docs/PRIVACY_FA.md) و نتیجهٔ اعتبارسنجی در [گزارش آزمون](docs/VALIDATION.md) ثبت می‌شوند.
