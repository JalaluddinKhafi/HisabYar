# حساب‌یار — پروژه آغازین اندروید

این پروژه یک نمونه آغازین آفلاین برای ثبت درآمد و مصرف به افغانی و دالر است. داده‌ها در SharedPreferences داخل برنامه ذخیره می‌شوند؛ هیچ مجوز اینترنتی در برنامه تعریف نشده است.

## ساخت APK فقط با گوشی
1. با مرورگر گوشی وارد GitHub شوید و یک مخزن جدید با نام `HisabYar` بسازید.
2. فایل‌های داخل این پوشه را به مخزن اضافه کنید. ساختار پوشه‌ها را حفظ کنید و فایل مخفی `.github/workflows/build-apk.yml` را نیز بارگذاری کنید.
3. در مخزن، بخش Actions را باز کنید و گردش‌کار `Build HisabYar APK` را اجرا کنید. اگر Actions غیرفعال است، آن را فعال کنید.
4. پس از موفقیت، وارد اجرای workflow شوید و از بخش Artifacts فایل `HisabYar-debug-apk` را دانلود کنید.
5. فایل ZIP دانلودشده را در گوشی استخراج کنید؛ فایل `app-debug.apk` را باز کنید و اجازه نصب از این منبع را فقط در صورت نیاز فعال سازید.

## حریم خصوصی و محدودیت‌ها
- برنامه به اینترنت نیاز ندارد و مجوز اینترنت ندارد.
- داده‌ها فقط در فضای خصوصی برنامه ذخیره می‌شوند؛ حذف برنامه یا پاک‌کردن داده‌های آن ممکن است اطلاعات را از بین ببرد. فعلاً پشتیبان‌گیری خودکار/فایل JSON واقعی وجود ندارد؛ نمایش متن برای کپی دستی ارائه شده است.
- این پروژه نمونه اولیه است و قبل از استفاده جدی از حساب‌های مالی باید روی دستگاه آزمایش شود.
- فایل APK ساخته‌شده با این workflow نسخه debug است، نه نسخه انتشار امضاشده.
